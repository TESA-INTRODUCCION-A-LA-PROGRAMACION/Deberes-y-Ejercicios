# Repositorio de la clase
¡Bienvenidos! En este repositorio subimos nuestros ejercicios y actividades.
También es el lugar donde practicamos Git y GitHub, como lo hacen los desarrolladores reales.

## Reglas (lo más importante)

1. **Solo toca tu propia carpeta.** Nunca edites ni borres archivos de otras personas.
2. **Nunca subas directamente a `main`.** Usa siempre una rama (branch) y un Pull Request. (El repositorio principal tendrá protección extra).
3. Sigue la convención de nombres de abajo.

## Estructura del repositorio

```
exercises/
├── 01-ejemplo-deber-1-calculadora/
│   ├── nombre_apellido/
│   │   └── calculadora.cpp
│   └── ...
└── 02-.../
```

## Convención de nombres

- Carpeta: `nombre_apellido` (minúsculas, sin tildes, y con `_` en lugar de espacios). Ejemplo: `maria_lopez`
- Archivos: descriptivos, en minúsculas y sin espacios. Ejemplos: `calculadora.cpp`, `deber1.cpp`, `suma_de_numeros.cpp`
