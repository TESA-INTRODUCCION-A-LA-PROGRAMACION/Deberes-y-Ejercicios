# Repositorio de la clase
¡Bienvenidos! En este repositorio subimos nuestros ejercicios y actividades.
También es el lugar donde practicamos Git y GitHub, como lo hacen los desarrolladores reales.

## Reglas (lo más importante)

1. **Solo toca tu propia carpeta.** Nunca edites ni borres archivos de otras personas.
2. **Nunca subas directamente a `main`.** Usa siempre una rama (branch) y un Pull Request. (El repositorio principal tendra proteccion extra).
3. Sigue la convención de nombres de abajo.

## Estructura del repositorio

```
exercises/
├── 01-Ejemplo-deber-1-calculadora/
│   ├── Tu_nombre_apellido/
│   │   └── calculadora.cpp
│   └── ...
└── 02-.../
```

## Convención de nombres

- Carpeta: `nombre_apellido` (minúsculas, sin espacios se usara _ en vez de espacio, sin tildes,). Ejemplo: `maria_lopez`
- Archivos: descriptivos y en minúsculas. Ejemplos: `calculadora.cpp` `deber1.cpp` `programaquehaceesto.cpp`
